# WordRun

Раннер для заучивания английских слов. Один статический сайт, без бэкенда:
слова и прогресс хранятся в localStorage браузера и никуда не отправляются.

- `index.html` — вся игра (разметка, стили, логика)
- `sw.js` — service worker, работа офлайн
- `manifest.webmanifest` — установка на домашний экран
- `icons/` — иконки приложения

## Что внутри
- Раннер с воротами: 2 или 3 варианта, управление тапом/свайпом/стрелками.
- Интервальные повторения (коробки Лейтнера), интервалы `2 / 6 / 15 / 40 / 100 / 260` ответов.
- Неправильные варианты подбираются похожими на правильный — угадать сложно.
- Импорт своего словаря: таб, тире, `=`, `;`, `|`, запятая; русская колонка определяется автоматически.
- Озвучка через Web Speech API, экспорт резервной копии в JSON.
